## 🚀 快速安装与环境部署

### 方式 A：自动化一键部署（推荐）
在仓库根目录下运行：
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
.\install.ps1
```
脚本将全自动检测并配置中科大高速镜像源、通过 WinGet 安装全部依赖与字体、安全备份既有配置并部署 Profile。

### 方式 B：手动快速安装
```powershell
# 1. 优先使用 WinGet 安装 CLI 工具链与 Nerd Font
winget install Microsoft.PowerShell Git.Git JanDeDobbeleer.OhMyPosh Fastfetch-cli.Fastfetch eza-community.eza sharkdp.bat ajeetdsouza.zoxide junegunn.fzf alexpasmantier.television duan.tre Nushell.Nushell sxyazi.yazi JesseDuffield.lazygit Neovim.Neovim BurntSushi.ripgrep.MSVC sharkdp.fd DEVCOM.JetBrainsMonoNerdFont --accept-source-agreements --accept-package-agreements

# (备选：通过 Scoop 安装)
# scoop install git oh-my-posh fastfetch eza bat zoxide fzf ripgrep fd lazygit neovim yazi television tre

# 2. 安装 PowerShell 扩展模块
Install-Module PSReadLine, Terminal-Icons, PSFzf -Scope CurrentUser -Force -SkipPublisherCheck

# 3. 部署与重载配置文件
Copy-Item .\Microsoft.PowerShell_profile.ps1 $PROFILE -Force
. $PROFILE
```

## ⌨️ 核心全局快捷键速查

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+R` | 交互式历史命令模糊搜索 | 由 PSFzf / FZF 提供，支持上下方向键检索历史 |
| `Ctrl+T` | 呼出 Television 智能模糊补全 | 基于当前命令输入自动匹配文件/目录/选项并填入 |
| `Alt+Z` / `zi` | Zoxide 交互式目录快跳 | 模糊匹配访问过的目录并实时跳转 |
| `Ctrl+F` | 模糊检索当前目录文件并填入命令行 | 配合 bat 语法高亮预览 |
| `Ctrl+G` / `lg` | 呼出 Lazygit 终端管理器 | 瞬间启动 Lazygit，退出后自动恢复原提示符 |
| `Ctrl+Z` | 撤销上次命令行输入 | PSReadLine Windows 模式增强 |
| `→` / `End` | 一键采纳历史/插件智能预测建议 | PSReadLine 智能补全 |
| `F2` | 切换预测展示视图 (内联 / 下拉列表) | ListView / InlineView 自由切换 |

## 📝 现代化命令别名与工具增强

### 1. 文件与目录列表（安全不破坏 PowerShell 对象管道）

| 命令 | 底层实现 | 说明 |
|------|----------|------|
| `ll` | `eza --long --icons=auto --group-directories-first` | 详细列表带图标与目录前置 |
| `la` | `eza --long --all --icons=auto ...` | 包含所有隐藏文件与点文件 |
| `lt` | `eza --tree --level=2 ...` | 2 层深度目录树状图预览 |
| `lt3` | `eza --tree --level=3 ...` | 3 层深度目录树状图预览 |
| `llg` | `eza --long --git --icons=auto ...` | 结合 Git 状态的文件详细列表 |
| `catc` | `bat --paging=never` | 语法高亮查看文件内容（不锁屏分页） |
| `dir` / `ls` / `cat` | 原生 PowerShell Cmdlet | 保留输出为 `FileInfo`/字符串对象，管道处理不报错 |

| 指令 | 作用 | 说明 |

| `tvt` | 代码全文检索与行定位 (`tv text`) | 极速全文检索，回车定位到编辑器指定行 |
| `tvb` | Git 分支交互式切换 (`tv git-branch`) | 交互式分支选择与瞬间切换 |

| `c [path]` | 快速启动 VS Code | 打开指定目录或文件 |

| `myip` | 查看本机网卡与 IP 地址 | 自动过滤虚拟回环与链路本地地址 |

### 3. 快速多级目录穿梭

- `..` ：返回上一层目录
- `...` ：返回上两层目录
- `....` ：返回上三层目录
- `mkcd <dir>` ：新建目录并直接进入

## ⚡ 性能调优与环境变量开关

本配置文件原生内置了多组环境开关，可在系统环境变量或 Profile 顶部声明以自定义体验：

```powershell
# 1. 禁用启动就绪面板与 Fastfetch（极速冷启动模式，启动耗时仅需 ~100ms）
$env:POWERSHELL_PROFILE_MINIMAL = '1'

# 2. 仅关闭 Fastfetch 动漫系统看板
$env:POWERSHELL_PROFILE_BANNER  = '0'

# 3. 仅关闭启动就绪状态卡片提示
$env:POWERSHELL_PROFILE_TIPS    = '0'

# 4. 禁用 Terminal-Icons 图标库以节省 ~500ms 导入耗时
$env:POWERSHELL_PROFILE_ICONS   = '0'

# 5. 指定固定主题或切换为 Starship 提示符
$env:POWERSHELL_THEME_MODE      = 'starship'   # 或 'random'
$env:POWERSHELL_POSH_THEME      = 'catppuccin_mocha.omp.json'
```
